## 📖 Overview
<a id="overview"></a>

**Souls of Tartarus** is an exhilarating Rogue-Lite dungeon crawler available on Windows, developed by Gin Motion. Set against the backdrop of Greek mythology, the game offers players a chance at rebirth by overcoming the lazy generals ruling the underworld. This latest version combines the replayability of a Rogue-Lite with the challenge of permadeath from Rogue-Like games. With no checkpoints, every run counts! 

Players can choose to be a wizard, swordsman, or grifter, navigating through perilous dungeons with a methodical approach to combat. The game’s engaging mechanics ensure you will be on the edge of your seat as you strive for victory in each run.
